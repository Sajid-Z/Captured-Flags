CHALLENGE DESCRIPTION:
----------------------
You're aboard a deep-space relay station when an incoming capture hits your
buffer: a mono audio recording labeled "0xfun". The analysts insist it's alien.
But the encoding style feels familiar. Like something humanity would send when
it wanted to be understood without sharing a language.

Dig into the signal, recover what it's really carrying, and extract the flag.
Format: 0xfun{}

FILES PROVIDED:
--------------
- Lines_of_Contact.rar → cover.png, record.wav

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   Extracted the RAR archive to find two files: cover.png (1600×1000 RGB)
   and record.wav (mono 16-bit PCM, 48 kHz, ~11.6 seconds).

   The challenge description ("something humanity would send when it wanted
   to be understood without sharing a language") strongly hints at the
   Voyager Golden Record — NASA's interstellar message that encodes images
   as audio waveforms with sync pulses marking scan lines.

2. ANALYZE THE AUDIO STRUCTURE

   The WAV file has three distinct regions:

   - 0.0–2.5 s: Noise / preamble (low-energy wideband signal)
   - 2.5–2.9 s: Pure 2 kHz calibration tone (±19660 amplitude, 24
     samples/cycle at 48 kHz)
   - 2.9–11.6 s: Image data separated by sync pulses

   The calibration tone matches the Voyager Golden Record format exactly.

3. LOCATE SYNC PULSES

   Each scan line is delimited by a sync pulse: a burst of 32 consecutive
   samples at −32767 (minimum 16-bit value). Searching for these yields
   1024 sync groups total.

   At group 511, there is a large gap of ~21952 samples (a second
   calibration tone), splitting the data into two images of 511 and 512
   scan lines respectively.

4. EXTRACT SCAN LINES

   Between consecutive sync pulses, the data samples (~352 per line)
   represent pixel brightness values for one horizontal scan line:

   - Dark pixels: baseline around −6500
   - Bright pixels: positive values up to +31000

   Each line varies between 350–354 samples due to minor drift, consistent
   with the original Voyager encoding scheme.

5. RENDER THE IMAGE

   Arranged each scan line as a row of a grayscale image with width 352.
   Pixel values were thresholded (values > 0 → white, else → black) to
   produce a clean binary image.

   The two decoded images (511×352 and 512×352) contain visual patterns
   with the flag readable in the rendered output.

6. READ THE FLAG

   The decoded image reveals the flag embedded in the Voyager-style
   encoded picture.

TOOLS USED:
-----------
- unrar (archive extraction)
- Python + numpy + PIL (WAV analysis, scan line extraction, image rendering)
