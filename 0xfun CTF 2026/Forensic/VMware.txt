CHALLENGE DESCRIPTION:
----------------------
I forgotten the password of my kali linux.
Fetch the flag from the provided VMware artifacts.

FILES PROVIDED:
--------------
- files.zip

SOLUTION:
---------

1. INITIAL RECONNAISSANCE
   
   The challenge folder contained a single file:
   - Forensic/VMWare/files.zip
   
   A normal unzip check failed because the outer zip structure is malformed.

2. IDENTIFY THE REAL CONTAINER
   
   Using archive inspection tools showed that `files.zip` contains an inner
   archive stream named `0xfunctf26.zip`.
   
   The clean inner archive was already present at:
   - Forensic/VMWare/files/0xfunctf26.zip

3. INSPECT VM METADATA
   
   Listed inner archive contents and found a full split VMware disk set:
   - kali-linux-2025.4-vmware-amd64-s001.vmdk ... s041.vmdk
   - .vmx / .vmdk descriptor / .nvram / vmware-0.log
   
   The `.vmx` annotation revealed:
   - Username: kali
   - Password: ****
   
   So direct login credentials were intentionally masked.

4. ANALYZE RUNTIME LOG
   
   In `vmware-0.log`, a useful activity artifact appeared:
   - `CPClipboard_SetItem` with data size 41
   
   This indicated user interaction/clipboard activity during the VM session,
   suggesting the flag or password may be left in disk/trace data.

5. STRING HUNT ACROSS VMDK EXTENTS
   
   Instead of reconstructing and booting the VM, performed streamed forensic
   search over all archive members for flag format:
   - `0xfun{...}`
   
   The hit was recovered from:
   - `0xfunctf26/kali-linux-2025.4-vmware-amd64-s016.vmdk`

6. VERIFY
   
   Re-scanned all VMDK extents and VM metadata files to check for alternate
   candidate flags/decoys. Only one valid flag-format result appeared.

TOOLS USED:
-----------
- unzip / 7z
- binwalk
- strings
- rg (ripgrep)
