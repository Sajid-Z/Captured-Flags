CHALLENGE DESCRIPTION:
----------------------
Here's a small drawing I put together. There isn't really anything in it,
as you can tell.
Flag Format: 0xfun{}

FILES PROVIDED:
--------------
- file.png

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   Received a PNG image (584x784, RGBA). At first glance it appeared to
   be a simple drawing with nothing hidden — matching the challenge name
   "Nothing Expected."

2. METADATA INSPECTION

   Ran exiftool on the image. It flagged a warning:
     "Text/EXIF chunk(s) found after PNG IDAT (may be ignored by some readers)"
   This indicated extra data embedded after the image data.

3. PNG CHUNK ANALYSIS

   Parsed the PNG chunks manually and found a large tEXt chunk (72 KB)
   with the keyword "application/vnd.excalidraw+json". This revealed
   the image was exported from Excalidraw, a browser-based drawing tool,
   which embeds its full scene data inside exported PNGs.

4. EXTRACT EXCALIDRAW DATA

   The embedded data used "bstring" encoding with zlib compression.
   Decoded the \uXXXX escape sequences back to raw bytes, then
   decompressed the zlib payload to recover the full Excalidraw JSON.

5. INSPECT SCENE ELEMENTS

   The JSON contained 44 elements:
   - 1 text element: "shh, this is a secret!!"
   - 1 arrow element
   - 42 freedraw elements (hand-drawn strokes)
   
   All freedraw strokes were colored #1e1e1e (near-black), drawn on
   a white background. The visible PNG showed these strokes, but the
   key insight was that the Excalidraw data preserved the full
   drawing — including content that may have been cropped, scrolled
   off-screen, or otherwise not obvious in the exported PNG.

6. VISUALIZE FREEDRAW PATHS

   Extracted all freedraw point coordinates from the JSON and plotted
   them using matplotlib to render the full scene without any cropping.
   The hand-drawn strokes spelled out the flag.

7. VERIFY

   Submitted the flag and it was accepted.

TOOLS USED:
-----------
- exiftool (metadata inspection)
- Python 3 (PNG chunk parsing, bstring decoding, zlib decompression)
- matplotlib (freedraw path visualization)
