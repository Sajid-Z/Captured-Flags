CHALLENGE DESCRIPTION:
----------------------
The electronic roulette uses a Mersenne Oracle with 624 internal spirits.
A waitress whispers: "The secret is 0xCAFEBABE".
Suffering ends in 30 minutes.
nc chall.0xfun.org 40839

FILES PROVIDED:
--------------
- roulette.py

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   The source code (roulette.py) reveals:
   - A MersenneOracle class wrapping Python's random.Random (Mersenne Twister)
   - Each "spin" returns: mt.getrandbits(32) ^ 0xCAFEBABE
   - The XOR key 0xCAFEBABE is given in the challenge description

2. UNDERSTAND THE VULNERABILITY

   The Mersenne Twister PRNG has an internal state of 624 32-bit integers.
   If an attacker observes 624 consecutive raw outputs, they can recover
   the full internal state and predict all future outputs.

   Since we know the XOR key, every obfuscated spin value can be trivially
   reversed: raw = spin_value ^ 0xCAFEBABE.

3. COLLECT 624 OUTPUTS

   Connected to the server and sent "spin" 624 times.
   XORed each returned value with 0xCAFEBABE to recover the raw MT output.

4. UNTEMPER AND CLONE THE STATE

   The Mersenne Twister applies a "tempering" transform to each state word
   before outputting it. To recover the internal state, each raw output
   must be "untempered" — reversing the four bitwise operations:
     y ^= y >> 18
     y ^= (y << 15) & 0xEFC60000
     y ^= (y << 7) & 0x9D2C5680
     y ^= y >> 11

   Applied the inverse of each operation to all 624 values, then loaded
   the recovered state into a Python Random object:
     clone.setstate((3, tuple(mt_state + [624]), None))

5. PREDICT AND SUBMIT

   Generated the next 10 raw MT outputs from the cloned generator.
   Sent "predict" to the server and provided the 10 values space-separated.
   The server confirmed the predictions and returned the flag.

TOOLS USED:

- Python 3 (socket communication, MT state cloning)
- netcat (initial protocol probing)
