CHALLENGE DESCRIPTION:
----------------------
Two files. One network.

You're handed a base model and an adapter. Alone, they're meaningless.
Together... well, that's for you to figure out.

Find the flag.

FILES PROVIDED:
--------------
- base_model.pt
- lora_adapter.pt

SOLUTION:
---------

1. INSPECT THE CHECKPOINTS

   `base_model.pt` contains a plain state_dict with:
   - layer1/2/3 + output weights and biases

   `lora_adapter.pt` contains:
   - layer2.lora_A
   - layer2.lora_B

2. IDENTIFY THE MERGE TARGET

   The LoRA shapes match layer2:
   - layer2.weight is (256, 256)
   - lora_A is (64, 256)
   - lora_B is (256, 64)

   So the effective merged matrix is:
   - merged = layer2.weight + (lora_B @ lora_A)

3. RECONSTRUCT THE HIDDEN DATA

   After merge, values are mostly quantized to 0..255/255 and form a
   256x256 grayscale image. Converting with:
   - img = round(merged * 255).astype(uint8)
   reveals embedded text.

4. READ THE FLAG

   The recovered image clearly shows:
   - apoorvctf{l0r4_m3rg3}

5. VERIFY ON CTFD

   Submitted once to challenge id 25 via CTFd API.
   Server response:
   - status: correct
   - message: Correct
