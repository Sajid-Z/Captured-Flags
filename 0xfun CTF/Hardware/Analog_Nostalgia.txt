CHALLENGE DESCRIPTION:
----------------------
We intercepted a raw signal capture from a VGA display adapter. The data appears
to be a single digitized frame from a 640x480 VGA output.

Flag format hint: 0xfun{}

FILES PROVIDED:
--------------
- signal.bin

SOLUTION:
---------

1. INITIAL RECONNAISSANCE
   
   Basic file checks immediately show this is not a plain image file:
   - `file signal.bin` -> "Zip archive, with extra data prepended"
   - The file starts with readable text: `check trailer. for hint.`
   
   So the main payload is raw data, with a ZIP trailer appended at the end.

2. EXTRACT THE TRAILER HINT
   
   Locate the embedded ZIP signature (`PK\\x03\\x04`) near EOF and parse it.
   It contains only `hint.txt` with a decoy string.
   
   Important takeaway:
   - The hint content is not needed for solving.
   - The real path is to decode the prepended raw capture.

3. IDENTIFY VGA SAMPLE LAYOUT
   
   After removing the 25-byte lead text, the payload length is:
   - `2,100,000` bytes
   
   This matches:
   - `800 * 525 * 5 = 2,100,000`
   
   Which strongly suggests one full VGA timing frame:
   - 800 pixels per line (including porch + sync)
   - 525 lines per frame (including porch + sync)
   - 5 bytes per sample: likely `R, G, B, HSYNC, VSYNC`

4. VERIFY CHANNEL ASSUMPTION
   
   Reshape payload to `(525, 800, 5)` and inspect channel stats:
   - RGB channels are 6-bit style values (`0..63`)
   - HSYNC and VSYNC are binary (`0/1`)
   - HSYNC low pulse width is 96 pixels on every line
   - VSYNC low pulse spans 2 full lines
   
   This exactly matches standard 640x480@60 VGA timing.

5. EXTRACT ACTIVE 640x480 IMAGE
   
   Sync alignment shows:
   - Active horizontal area: `x = 0..639`
   - Active vertical area: `y = 0..479`
   
   So extract:
   - `frame = samples[:480, :640, :3]`
   
   Scale RGB from 6-bit to 8-bit and save as PNG (`signal_frame.png`).

6. READ THE FLAG
   
   The reconstructed frame visibly contains the flag text.
   Recovered flag:
   - `0XFUN{AN4L0G_IS_N0T_D3AD_JUST_BL4NKING}`
