CHALLENGE DESCRIPTION:
----------------------
We intercepted a raw signal capture from an HDMI display adapter. The data
appears to be a single digitized frame from a 640x480 HDMI output.

FILES PROVIDED:
--------------
- signal.bin

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   Examined signal.bin (1,680,216 bytes) with a hex editor.
   - First 16 bytes: ASCII header "check end." (padded).
   - Last ~200 bytes: a ZIP archive containing hint.txt.
   - Middle 1,680,000 bytes: raw TMDS-encoded HDMI frame data.

   The ZIP hint confirmed the TMDS encoding approach.

2. UNDERSTAND THE DATA LAYOUT

   1,680,000 bytes / 4 bytes per word = 420,000 words.
   420,000 = 800 x 525, which matches standard 640x480 HDMI timing:
   - 800 pixels per line (640 active + 160 blanking)
   - 525 lines per frame (480 active + 45 blanking)

   Each 32-bit word packs three 10-bit TMDS channels:
   - Bits [9:0]   = Channel 0 (Blue)
   - Bits [19:10]  = Channel 1 (Green)
   - Bits [29:20]  = Channel 2 (Red)

3. IDENTIFY BLANKING REGIONS

   TMDS control tokens (0x354, 0x0AB, 0x154, 0x2AB) mark blanking.
   Scanning each row revealed:
   - Columns 640-797: horizontal blanking (control tokens)
   - Rows 0-34 and 515-524: vertical blanking (all-black pixels)
   - Active image area: columns 0-639, rows 35-514 (exactly 640x480)

4. DECODE TMDS TO RGB

   Each 10-bit TMDS code was decoded back to 8-bit pixel data using
   the standard TMDS decoding algorithm:
   - Bit 9: inversion flag (if set, invert bits [7:0])
   - Bit 8: transition mode selector (XOR vs XNOR)
   - Bits [7:0]: transition-minimized pixel data

   Decoding steps per channel:
   a) If bit 9 is set, invert the lower 8 bits
   b) Recover q_m[0] = decoded bit 0
   c) For bits 1-7: apply XOR (bit8=1) or XNOR (bit8=0) with
      the previous bit to recover each original pixel bit

   Built a lookup table for all 1024 possible 10-bit codes.

5. RECONSTRUCT THE IMAGE

   Extracted the 640x480 active region and applied TMDS decoding
   to each pixel's three channels to recover RGB values.
   Saved the result as a PNG image.

6. READ THE FLAG

   The decoded frame shows a Kirby meme image:
   "Kirby BEATS THE ABSOLUTE [censored] OUT OF [censored]
    WITH AN HDMI CABLE DELUXE"

   The flag is rendered in white text near the bottom of the frame.

-----------
- xxd / hex dump (file structure analysis)
- Python + struct (TMDS decoding)
- Pillow / PIL (image reconstruction)
- Tesseract OCR (text extraction, verified visually)
