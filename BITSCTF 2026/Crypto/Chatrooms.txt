CHALLENGE DESCRIPTION:
----------------------
Move up the levels of the chatrooms to reach the flag.
Call the boss with @boss for hints.
The secret is the private key of the vulnerable member in hex preceded by 0x.

FILES PROVIDED:
--------------
- Remote service only
- nc 20.193.149.152 1342

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   Connected to the service and observed three progressive rooms.
   Each room leaked ECDSA signatures and small hints through @boss.
   The task in every room was to submit a private key in hex (0x...).

2. ROOM 1 (ALPHA_01 - FIXED NONCE)

   Room 1 was standard ECDSA nonce reuse with known nonce:
   - k = 0xDEADC0DE
   - Signature from Alpha_01 gives (r, s) on known message m

   Using:
   - s = k^{-1}(z + r*d) mod n
   - z = sha256(m)

   Rearranged:
   - d = (s*k - z) * r^{-1} mod n

   Submitting this d as 0x... validated Room 1.

3. ROOM 2 (EXARCH_01 + RACHEL_RELAY CHUNKS)

   Room 2 changed behavior:
   - Exarch_01 gives exactly two signatures
   - Rachel_Relay leaks 8 unique pairs:
     [A_CHUNK:........ | B_CHUNK:........]

   The working model was affine-related nonces for Exarch:
   - k2 = a*k1 + b  (mod n)
   - a = concat(all 8 A_CHUNK values in seen order)
   - b = concat(all 8 B_CHUNK values in seen order)

   With:
   - k1 = (z1 + r1*d)/s1
   - k2 = (z2 + r2*d)/s2

   Solve directly:
   - d = (a*s2*z1 - s1*z2 + b*s1*s2) * (r2*s1 - a*r1*s2)^{-1} mod n

   Submitting that d validated Room 2.

4. ROOM 3 (CRACKED_CORE - NONCES NOT MESSAGE-RELATED)

   Clarification said Room 3 nonces are not related to message content.
   Stream analysis showed 5 unique Cracked_Core signatures repeating.

   Let per-signature nonce be:
   - k_i(d) = (z_i + r_i*d) * s_i^{-1} mod n
   (tested with s_i and n-s_i due ECDSA sign ambiguity)

   Then model nonce sequence with weak quadratic recurrence:
   - k_{i+1} = A*k_i^2 + B*k_i + C  (mod n)

   For i = 0..3 this gives 4 linear equations in (A,B,C).
   A solution exists iff determinant is zero:
   - det([k_i^2, k_i, 1, k_{i+1}] for i=0..3) = 0

   Since each k_i is linear in d, this determinant becomes a polynomial in d.
   Process used in solver:
   - iterate all 5! orderings of the 5 signatures
   - iterate all s / (n-s) combinations
   - build determinant polynomial
   - solve roots mod n with PARI (polrootsmod via cypari2)
   - for each candidate d:
     - solve (A,B,C) from first 3 transitions
     - verify 4th transition
     - recover pubkey from d and match recovered Cracked_Core pubkey

   The surviving d is the Room 3 secret.
   Submitting it opens the vault and prints the flag.

5. AUTOMATION

   Full solve was automated in:
   - chatrooms_solver.py

   It now solves:
   - Room 1 (known nonce)
   - Room 2 (affine nonce relation)
   - Room 3 (quadratic nonce recurrence + modular root solving)

TOOLS USED:
-----------
- Python
- cypari2 (PARI polrootsmod for roots modulo secp256k1 order)
- coincurve (ECDSA pubkey recovery / validation)
- nc for manual probing
