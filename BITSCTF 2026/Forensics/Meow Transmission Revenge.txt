CHALLENGE DESCRIPTION:
----------------------
The cat returned with a noisy RGB transmission. Metadata hinted at a "triple
personality" and Arnold-style transforms. Recover the hidden flag.

FILES PROVIDED:
--------------
- meow_transmission_revenge.zip
  - README.md
  - revenge_transmission.png

SOLUTION:
---------

1. INITIAL RECONNAISSANCE

   Extracted the zip and inspected metadata using `exiftool`.
   The PNG comment contained per-channel instructions:
   - Red Personality:   Styles [1,2,1], Spins [47,37,29], Sequence [1,2,3]
   - Green Personality: Styles [2,1,2], Spins [20,50,20], Sequence [2,3,1]
   - Blue Personality:  Styles [1,1,1], Spins [10,80,10], Sequence [3,1,2]

   It also says:
   "Hint: I stopped counting my spins (periods)."

2. IDENTIFY THE TRANSFORM FAMILY

   From the first "Meow Transmission" challenge, this is Arnold Cat Map based.
   The two style matrices are:
   - Style 1: [[1,1],[1,2]]
   - Style 2: [[1,2],[1,3]]

   Image size is N=128, and each channel must be decoded independently.

3. REVERSE EACH CHANNEL WITH ITS OWN PERSONALITY

   Split the RGB image into R/G/B channels.
   For each channel:
   - Use that channel's style list, spin list, and sequence list.
   - Apply inverse Arnold transforms in reverse sequence order.
   - Use the listed spin counts directly (matching the "stopped counting periods"
     hint, i.e., no rhythm-period subtraction trick needed).

4. EXTRACT THE PAYLOAD BITPLANE

   After decoding, bit 0 (LSB) of each channel produced the same sparse text
   mask. Combining them with OR/XOR/majority yielded the same readable output.

   The clearest recovered image was:
   - `Forensics/Meow Transmission Revenge/analysis/comb_or.png`

5. READ THE PIXEL TEXT

   The hidden text appears across 3 lines:

   BITSCTF{r3v3ng3_
   0f_th3_c4t_m4p_m
   4st3r}

   Joining lines gives:
   BITSCTF{r3v3ng3_0f_th3_c4t_m4p_m4st3r}

6. VERIFY

   Confirmed flag format `BITSCTF{...}` and validated the full reconstructed
   phrase from the decoded bitmap.

TOOLS USED:
-----------
- unzip
- exiftool
- strings / binwalk (quick checks)
- Python (Pillow + NumPy) for Arnold-map reversal and bitplane extraction
